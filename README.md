# My Tech Card — Starter Project

Αυτό είναι το αρχικό project για την εργασία **Git & GitHub**.

## Περιεχόμενα
- `index.html`: περιεχόμενο της ιστοσελίδας.
- `styles.css`: εμφάνιση της ιστοσελίδας.
- `script.js`: λειτουργία του κουμπιού (η συνάρτηση είναι σκόπιμα κενή).
- `assets/logo.svg`, `assets/illustration.svg`: δύο τοπικές εικόνες SVG.

## Πώς το ανοίγω;
Ανοίγω το αρχείο `index.html` στον browser. Δεν απαιτείται εγκατάσταση ή server.

## Εργασία στον κλάδο `main`
1. Δημιουργώ δικό μου GitHub repository για αυτό το project.
2. Προσθέτω όλα τα αρχεία και κάνω το αρχικό commit (`Initial project files`).
3. Στο `index.html` αντικαθιστώ το `[ΤΟ ΟΝΟΜΑ ΣΟΥ]` με το όνομά μου ή ένα ψευδώνυμο.
4. Κάνω δεύτερο commit (`Personalize welcome text`) και δημοσιεύω τις αλλαγές στο `main`.

## Εργασία στον κλάδο `experimental`
1. Δημιουργώ το νέο branch `experimental` από το ενημερωμένο `main`.
2. Μόνο σε αυτό το branch επεξεργάζομαι το `script.js`.
3. Συμπληρώνω τη συνάρτηση `showPersonalMessage()` έτσι ώστε με το πάτημα του κουμπιού να εμφανίζεται μια δική μου φράση στην περιοχή με id `result`.
4. Δοκιμάζω στο browser ότι λειτουργεί.
5. Κάνω commit (`Implement personal message feature`) και push / publish στο `experimental`.
6. Δεν κάνω merge με το `main` πριν την αξιολόγηση.

## Τελικός έλεγχος
- Υπάρχουν στο GitHub τα δύο branches `main` και `experimental`.
- Η νέα λειτουργία υπάρχει **μόνο** στο `experimental`.
- Το ιστορικό περιέχει ξεχωριστά commits αρχείων, προσωποποίησης και νέας λειτουργίας.
- Το repository περιέχει όλα τα αρχεία και τις εικόνες.

> Μην ανεβάζεις κωδικούς πρόσβασης, κλειδιά API ή άλλα προσωπικά/ευαίσθητα δεδομένα.
